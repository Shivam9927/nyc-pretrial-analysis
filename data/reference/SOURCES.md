# Reference tables

Hand-entered from the official DCJS *Supplemental Pretrial Release Summary Tables, 2019-2024*
(https://criminaljustice.ny.gov/supplemental-pretrial-release-summary-tables-2019-2024).

- `official_table3_nyc.csv`: Table 3, Pretrial Release Decisions at Arraignment, NYC Criminal Courts.
  "Cases disposed at arraignment or with unknown pretrial release decisions are not included in the table."
- `official_table11_12_nyc.csv`: Table 11 (failure to appear, i.e. a bench warrant issued between
  arraignment and disposition) and Table 12 (rearrest within 180 days, fingerprintable misdemeanor
  or felony) for NYC Criminal Courts, by release type. "Bail paid" means bail paid within 5 days.

Re-check these numbers against the PDF if DCJS republishes the tables.
